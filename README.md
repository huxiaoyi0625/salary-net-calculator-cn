# Salary Compute

一个用于反推税前月薪的小型 Python 命令行工具。

不知道现在自己的工资到手到底是多少？

同样是 60 万年包，12 薪、14 薪、16 薪的实际到手可能差不少；同样是 12% 公积金，北京、上海、深圳、杭州因为社保和公积金基数上限不同，算出来的税前月薪也不一样。更麻烦的是，年终奖单独计税还有跳档问题，直觉上“多发几个月奖金更划算”并不总是成立。

这个小工具就是为这种场景写的：先告诉它你希望一年实际拿到多少“到手 + 公积金”，它会反推出不同城市、不同薪资结构、不同公积金比例下，大概需要多少税前月薪。

## 计算目标

程序里的目标收入口径是：

```text
年度目标收入 = 全年现金到手 + 个人公积金 + 单位公积金
```

也就是说，公积金账户入账金额会被视为有效收入的一部分。

## 支持维度

城市：

- 杭州
- 深圳
- 上海
- 北京

薪资结构：

- 12 薪
- 13 薪
- 14 薪
- 15 薪
- 16 薪

公积金比例：

- 5%
- 7%
- 12%

## 运行方式

本项目不依赖第三方库，直接使用 Python 运行即可。

```powershell
python main.py 600000
```

也可以使用命名参数：

```powershell
python main.py --target 600000
```

输出明细：

```powershell
python main.py --target 600000 --verbose
```

## 年终奖计税

默认使用全年一次性奖金单独计税：

```powershell
python main.py --target 600000 --bonus-tax separate
```

也支持并入综合所得：

```powershell
python main.py --target 600000 --bonus-tax merge
```

或者自动选择税更少的方式：

```powershell
python main.py --target 600000 --bonus-tax better
```

## 主要计算假设

- 目标收入为年度金额，单位为元。
- 12 薪表示没有年终奖。
- 13/14/15/16 薪表示 12 个月正常工资，剩余薪数作为全年一次性奖金。
- 社保和公积金只按 12 个月正常工资缴纳，年终奖不缴五险一金。
- 公司公积金比例默认等于个人公积金比例。
- 社保、公积金按税前月薪作为缴费基数，并应用各城市上下限。
- 不考虑专项附加扣除、补充公积金、企业年金、商业健康险等额外扣除。
- 深圳按非深户、职工医保一档估算。

## 数据更新

社保、公积金基数和比例集中配置在 `main.py` 的 `CITIES` 里：

```python
CITIES: tuple[CityConfig, ...] = (...)
```

如果各地发布了新的社保年度或公积金年度数据，优先更新这里：

- `ContributionItem`：养老、医疗、失业等个人缴费比例和基数上下限。
- `fund_base_min`：公积金缴存基数下限。
- `fund_base_max`：公积金缴存基数上限。
- `notes`：输出时展示的数据口径说明。

个税税率表配置在：

```python

BONUS_TAX_BRACKETS
```
